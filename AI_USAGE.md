## AI Disclosure and Governance

This project uses an AI-assisted development workflow via Claude Code. It is built under strict "human-in-the-loop" supervision with zero creative autonomy granted to the tool.

*   **The Engine & Core Backend** is Architecture-Driven. The system architecture, internal mechanisms, and code style are completely micromanaged by a human. AI is used strictly to accelerate writing the code, and every line is reviewed and vetted.
*   **The Demo Application** is Results-Driven. The accompanying demo is focused entirely on visual presentation and functional correctness. AI is used heavily here to quickly build out user interfaces and boilerplate, with human oversight focused on the UI behavior.
